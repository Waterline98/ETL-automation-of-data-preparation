# ETL automation of data preparation

Проект направлен на создание пайплайна для работы с данными. Задача — обеспечить автоматизированное получение данных и их выгрузку в таблицы, а также построить витрину данных.


## Этапы работы

Провести миграцию схемы и данных в таблице mart.f_sales.

Построить витрину данных mart.f_customer_retention и наполнить её данными по возвращаемости клиентов в разрезе недель.

## Описание рабочих файлов

Папка dags:

sprint3.py — пайплайн для работы с данными.

Папка migrations:

mart.f_customer_retention.sql — SQL‑запросы на создание таблицы mart.f_customer_retention, заполнение её данными и их обновление.
